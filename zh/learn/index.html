BTX 是什么？

固定供应量

与比特币一样，最多 2100 万枚 BTX。大约每 90 秒出一个区块；每个区块 20 BTX 的奖励每 525,000 个区块减半一次，约每 18 个月一次。

来源 ↗

矩阵乘法挖矿

矿工不做哈希运算，而是计算大型矩阵乘法，这正是 AI 加速器擅长的工作。自区块 185,000 起，自行验证区块的节点要在合格的 NVIDIA（CUDA）或 Apple（Metal）GPU 上精确重算每个区块；没有这种 GPU 的节点依赖他人签名的验证结果。无法用 CPU 挖矿。

来源 ↗

后量子签名

币由旨在抵御量子计算机的签名锁定：日常支付使用 ML-DSA-44（NIST FIPS 204），SLH-DSA（FIPS 205）作为基于哈希的备用方案。这类 P2MR 地址以 btx1z 开头。

来源 ↗

基于 Bitcoin Knots

节点源自 Bitcoin Knots v29.2（Bitcoin Core 的一个变体）。btxd、btx-cli、RPC 接口和 PSBT 的用法与比特币用户熟悉的一样；不同的是工作量证明、签名和部分网络规则。

来源 ↗

预发布版 v0.34.16 的新内容

自 2026 年 11 月 7 日起发布的预发布版，仅限 Linux x86_64。它打包了 0.35 的评审分支；0.35 版本线仍在继续。开发者表示这不是经过发布验证的版本。当前正式版仍为 v0.34.15。

从钱包预签名互换领取交易

自 0.34.13 起，互换的领取交易可以在注资时签好，之后由任何掌握秘密的人完成。htlc_presign 和 p2mr_leaf 把手工构造的交易变成钱包中的一个步骤。手续费在预签名时就已确定，领取交易必须在退款高度之前得到确认。

开放端口更少的模型网络

AI 模型网络默认开启，监听 TCP 29447。v0.34.16 在使用 -listen=0 或代理时不再打开该端口，会通过 UDP 29448 在本地网络中寻找模型节点，并新增一个本地安全守护程序。-modelnet=0 可全部关闭；它不会花费币。

来源 ↗

使用代理时关闭自动更新

位于代理之后、或 -onlynet 排除了 IPv4 和 IPv6 的节点，默认不再检查更新。其他所有主网节点仍会查询 btx.dev，并自行安装更新的签名版本，除非设置 autoupdateseamless=0。

来源 ↗

Atlas，第二个桌面应用

Linux 压缩包在保留 btx-qt 的同时新增 btx-atlas。Atlas 需要 glibc 2.39、WebKitGTK 4.1、GTK 3、Ayatana 托盘库和 zenity。btx-qt 和 ZeroMQ 在 v0.34.15 中就已提供。

更清楚的备份警告

钱包打包备份现在会说明，其中的描述符文件无需钱包密码即可花费，并对加密钱包发出警告。用早期版本制作的备份也包含同一个文件。

切换之前

  • 没有 CUDA、macOS 或 Windows 压缩包。GPU、挖矿或签名节点升级到 v0.34.16 会失去 GPU 路径；这些节点请继续使用 v0.34.15。
  • 此压缩包中的 btx-qt 需要 glibc 2.43，无法在 Ubuntu 24.04 或 Debian 13 上启动；btxd 和 btx-cli 需要 2.38。
  • 解压整个压缩包，并从中运行 bin/btxd。单独复制出来的 bin/btxd 会直接退出。
  • 从创世区块开始同步仍会停在区块 126,978（#272）。请从快照开始。

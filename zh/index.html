社区枢纽

BTX.community

一个面向所有关注 BTX 的人的社区页面：BTX 是什么、如何挖矿、如何运行节点，以及在哪里获得帮助。由社区成员运营，而非公司。

你想从哪里开始？

BTX 新手

BTX 是比特币的后量子分叉，拥有固定的最大供应量和自己的工作量证明（MatMul）。它由开放的社区维护，而非公司。

  1. 阅读官方介绍和文档。它针对 v0.33.2 编写；较新版本在部分地方有所不同。 ↗
  2. 用通俗的方式查看网络当前的运行情况。 ↗
  3. 在社区聊天（Discord、Telegram）中提问。 →
  4. 永远不要泄露你的助记词或私钥。社区里没有人会向你索要；主动私信提供帮助或“客服”的都是骗局。

挖矿

挖矿需要一块 GPU。你可以连接自己的节点单独挖矿并保留每个区块，也可以加入矿池以获得更稳定的收益。

  1. 从我们的链接列表中选择挖矿软件：例如 easyBTX（适用于 Mac 和 Linux 的应用；在 Windows 上通过 WSL）或 matador（开源）。 →
  2. 优先选择较小的矿池。当一个矿池找到大多数区块时，网络就依赖于它；状态页显示当前各矿池的份额。 ↗
  3. matador 的快速入门包含一个不属于你的示例收款地址，以及两个已下线的矿池。务必填入你自己的 btx1z 地址和我们链接列表中的矿池。 →
  4. NVIDIA 显卡有问题？官方 CUDA 故障排除指南可以帮忙；其中部分内容描述的是区块 185,000 之前的 CUDA 路径。 ↗

运行节点

每个节点都会转发区块，让网络保持可达。只有配备通过 btxd 自检的 GPU，节点才会自行验证每个区块。没有这样的 GPU，就把它作为受信任镜像运行，跟随至少两个签名者签署的验证结果；否则它会停止同步。签名者的要求最高。

  1. 在家最简单的开始方式：easynode 帮你安装并监管 btxd。 ↗
  2. 在服务器上：官方 Linux 版本需要 glibc 2.38 或更新版本（Ubuntu 24.04、Debian 13）；GPU 节点使用 -cuda13 压缩包（Blackwell 显卡）。v0.34.16 预发布版没有 CUDA 构建，因此 GPU 节点继续使用 v0.34.15。当前正式版没有官方 Windows 压缩包。 ↗
  3. 使用每日签名快照，几分钟内追上进度。从创世区块开始的同步目前会停在区块 126,978（issue #272）。 ↗
  4. 节点卡在某个高度？节点帮助页面解释了每种已知情况及其解决方法。 ↗
  5. 签名者（GPU 证明者）需要一块通过 btxd 自检的 GPU，并且必须保持在线。官方 CUDA 压缩包支持 Blackwell 显卡（sm_120）；其他 NVIDIA 显卡需要从源代码编译，而且可能不合格。请遵循开发者的运维手册。 ↗

成为 BTX 开发者

节点软件是开源的，任何人都可以在 GitHub 上向它提交拉取请求。开发者中心会告诉你以及你使用的 AI 工具，如何构建、测试一项更改并为其编写文档，使它能够被合并，以及哪些工作仍然开放。

  1. 从开发者页面开始：入门步骤、级别、测试覆盖率和开放任务。 →
  2. 把智能体文件交给你的 AI 工具（Claude Code、Cursor、Codex 或其他工具）。 ↗
  3. 参考实现及其针对智能体的自有规则。 ↗

    先检查

    购买或接收 BTX 之前

    1. 在收到资金之前先做备份。在 btxd 中，backupwalletbundlearchive 会写出一个加密文件；把它和它的密码分开离线保存。任何备份都能花费你的币：普通导出文件立即可以，压缩档案在打开后可以。恢复一次以测试备份。
    2. 完整核对收款地址，而不只是开头和结尾。BTX 地址以 btx1z 开头。
    3. 先发送一小笔测试金额。至少等待 10 个确认后再视为最终到账；链上每天都会发生几次短暂的重组。
    4. 在使用交易所或场外卖家之前，先确认提现确实可行。网站上的价格并不等于一个你能卖出的市场。
    5. 其他币也使用 BTX 这个代码交易。只有充值地址以 btx1z 开头的市场才属于这条链。
    6. “模型”价格或“参考”价格只是估算，并不是任何人必须兑现的报价。
    7. 正规的人绝不会索要你的助记词。提供帮助、“找回”或保证收益的消息都是骗局。

    安装节点版本之前

    1. 只从 github.com/btxchain/btx/releases 下载节点版本。是否信任 easynode 或快照等社区工具由你自己决定；请核验它们的签名。
    2. 最近的版本没有签名的校验和文件；最后一个带 SHA256SUMS.asc 的版本是 v0.34.6。GitHub 在发布页面为每个文件显示 SHA-256：用 “shasum -a 256 <文件>”（Linux 上用 “sha256sum”）进行比对。
    3. 这只能证明文件就是 GitHub 上的那个，而不能证明是谁构建的。如果你在意这一点，请自行编译带标签的源代码。
    4. 先确定节点的角色。自行验证区块需要一块合格的 NVIDIA 或 Apple GPU。没有的话，就以至少两个签名者的受信任镜像方式运行，否则节点会停下来。
    5. 新节点无法从创世区块开始同步：v0.34.15 和 v0.34.16 都会停在区块 126,978。请从签名快照开始，在有版本修复之前不要运行 -reindex。
    6. 有两项默认设置需要你决定：btxd 会自行从 btx.dev 安装更新的签名版本（autoupdateseamless=0 只提示，autoupdate=0 不再检查）；模型网络监听端口 29447（modelnet=0 可关闭）。
    7. 升级前先用 btx-cli stop 停止节点，并等待 btxd 完全退出；不要强行结束进程。然后备份数据目录和钱包。
    8. 升级前请阅读发布说明。有些版本会在固定区块高度改变规则；临近时本页会显示倒计时。此外，每个版本在构建约两年后会停止运行；当前版本将在 2028 年 11 月到期。
    9. Linux 程序需要 glibc 2.38 或更新版本（Ubuntu 24.04、Debian 13）。v0.34.15 提供 Linux、带 CUDA 的 Linux 和 Apple Silicon Mac 的压缩包；没有官方 Windows 版本。
    10. 预发布版（rc 以及 v0.34.16）仅供测试。v0.34.16 没有 CUDA 版本：GPU、挖矿或签名节点请继续使用 v0.34.15。

    挖矿

    4 个步骤

    挖矿需要一块 GPU。你可以连接自己的节点单独挖矿并保留每个区块，也可以加入矿池以获得更稳定的收益。

    • 选择挖矿软件 →

      例如 easyBTX（适用于 Mac 和 Linux 的应用；Windows 上通过 WSL）或 matador（开源）。

    • 优先选择较小的矿池 ↗

      如果一个矿池找到大部分区块，网络就会依赖它；状态页显示当前份额。

    • 使用你自己的 btx1z 地址 →

      matador 的快速入门里有一个不属于你的示例收款地址和两个已下线的矿池。请填写你自己的地址和我们链接列表中的矿池。

    • NVIDIA 显卡出现问题 ↗

      官方 CUDA 故障排查指南；其中部分内容描述的是区块 185,000 之前的 CUDA 方式。

    运行节点

    7 个步骤

    每个节点都会转发区块，让网络保持可达。只有配备通过 btxd 自检的 GPU，节点才会自行验证每个区块。没有这样的 GPU，就把它作为受信任镜像运行，跟随至少两个签名者签署的验证结果；否则它会停止同步。签名者的要求最高。

    • 在家最简单的开始：easynode ↗

      为你安装并监控 btxd。

    • 在服务器上 ↗

      v0.34.16 有两个 Linux x86_64 压缩包，需要 glibc 2.38 或更新（Ubuntu 24.04、Debian 13）：一个普通版，一个用于 GPU 节点的 -cuda13（sm_120：Blackwell RTX 50 和 RTX PRO 显卡；不含驱动）。没有官方 Windows 或 macOS 压缩包。

    • 安装之前：检查清单 →

      从哪里下载、如何校验文件，以及持有资金的节点应如何设置。

    • 从签名快照开始 ↗

      几分钟即可追上。目前从创世区块同步会停在区块 126,978（issue #272）。

    • 节点卡在某个高度？ ↗

      节点帮助说明了每种已知情况及其解决办法。

    • 有闲置的机器？ →

      为 BTX 提供基础设施的七种方式，从节点到 fuzz box。

    • 运行签名者 ↗

      签名者（GPU 证明者）需要一块通过 btxd 自检的 GPU，并且必须保持在线。官方 CUDA 压缩包支持 Blackwell 显卡（sm_120）；其他 NVIDIA 显卡需要从源代码编译，而且可能不合格。请遵循开发者的运维手册。

    先检查

    购买或接收 BTX 之前

    7 项检查
    1. 在收到资金之前先做备份。在 btxd 中，backupwalletbundlearchive 会写出一个加密文件；把它和它的密码分开离线保存。任何备份都能花费你的币：普通导出文件立即可以，压缩档案在打开后可以。恢复一次以测试备份。
    2. 完整核对收款地址，而不只是开头和结尾。BTX 地址以 btx1z 开头。
    3. 先发送一小笔测试金额。至少等待 10 个确认后再视为最终到账；链上每天都会发生几次短暂的重组。
    4. 在使用交易所或场外卖家之前，先确认提现确实可行。网站上的价格并不等于一个你能卖出的市场。
    5. 其他币也使用 BTX 这个代码交易。只有充值地址以 btx1z 开头的市场才属于这条链。
    6. “模型”价格或“参考”价格只是估算，并不是任何人必须兑现的报价。
    7. 正规的人绝不会索要你的助记词。提供帮助、“找回”或保证收益的消息都是骗局。

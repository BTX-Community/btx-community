挖矿软件 5

  • 32 easyBTX ↗ gpumaclinuxwslclosed source 一键挖矿应用，内置自托管钱包，适用于 Apple Silicon Mac 和 Linux（在 Windows 上通过 WSL）。 备注: 闭源；构建版本未签名，因此请核对发布页面上的 SHA-256。它默认在 BTX Pool 上开始挖矿。2026 年 8 月时，其开发者费用被列为 5%；请在应用中查看当前费率。
  • 33 matador ↗ gpunvidiaopen source 开源 GPU 挖矿软件（NVIDIA、CUDA），可连接自己的节点单独挖矿，也可加入矿池。 备注: 最后更新于 2026-08-21。其 README 中的快速入门包含一个示例收款地址和两个已下线的矿池（minebtx、Byron）；三者都要替换。矿池模式下收取 1% 的开发者费用；除非用 --no-auto-update 启动，否则它会自动更新。仅支持 NVIDIA Ampere（RTX 30 系列）或更新的显卡。
  • 34 nekominer ↗ gpunvidialinuxhiveosclosed source 适用于多种币的 NVIDIA（CUDA）挖矿软件；BTX 对应算法 btxv4，即自区块 185,000 起的工作量证明。其 README 提供了用于 ninjaraider 和 BTX Pool 的命令。 备注: 该挖矿软件的源代码未公开：仓库包含脚本和二进制版本，没有许可证。开发者费用为 2%，在 ninjaraider 上为 0%。
  • 35 ForgeMiner ↗ gpunvidiawindowshiveosclosed source 支持 BTX 的多币种 GPU 挖矿软件（自 1.6.0 版起支持 MatMul v4.7）；其 BTX 示例使用 BTX Pool。挖 BTX 仅支持 NVIDIA 显卡。 备注: 闭源（其 README 中写明）。挖 BTX 时收取 2% 的开发者费用。
  • 36 Solo mining helpers (btxd) ↗ soloofficialopen sourcescripts 连接你自己的 btxd 单独挖矿的官方脚本：一个感知健康状态的挖矿循环、启动和停止脚本，以及钱包备份。对于更大规模的部署，README 指向 getblocktemplate 配合外部挖矿软件的用法。 备注: 挖矿需要一块合格的 GPU 和一个自行验证区块的节点（matmulvalidation=consensus，即默认值），而不是受信任镜像。参见 GPU 运维手册。

  • 40 Node help ↗ helpstuck heights 已知的卡住高度，以及原因和解决方法。
  • 41 AInode ↗ macmodel networkdesktop easyBTX 团队的 Mac 应用（Apple Silicon，macOS 13 或更高版本），通过 BTX 模型网络获取开放的 AI 模型，并在你的 Mac 上运行。它只下载；从不对外提供模型，也不付款或赚取收益。 备注: 采用 MIT 许可证；此仓库只包含下载文件和发布说明。请比对每个版本附带列出的 SHA-256。

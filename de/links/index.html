Miner 5

  • 32 easyBTX ↗ gpumaclinuxwslclosed source Miner-App mit einem Klick und eingebauter selbstverwahrter Wallet, für Apple-Silicon-Macs und Linux (unter Windows über WSL). Hinweis: Closed Source; die Builds sind unsigniert, daher die SHA-256 auf der Release-Seite prüfen. Startet standardmäßig auf BTX Pool. Im August 2026 wurde eine Dev-Gebühr von 5 % genannt; die aktuelle Gebühr in der App prüfen.
  • 33 matador ↗ gpunvidiaopen source Open-Source-GPU-Miner (NVIDIA, CUDA), solo gegen den eigenen Node oder im Pool. Hinweis: Letzte Änderung 2026-08-21. Im Schnellstart des README stehen eine Beispiel-Auszahlungsadresse und zwei nicht erreichbare Pools (minebtx, Byron); alle drei ersetzen. 1 % Dev-Gebühr im Pool-Modus; aktualisiert sich selbst, außer beim Start mit --no-auto-update. Nur NVIDIA Ampere (RTX-30-Serie) oder neuer.
  • 34 nekominer ↗ gpunvidialinuxhiveosclosed source NVIDIA-Miner (CUDA) für mehrere Coins; BTX läuft als Algorithmus btxv4, der Proof-of-Work seit Block 185.000. Das README enthält Befehle für ninjaraider und BTX Pool. Hinweis: Der Quellcode des Miners ist nicht veröffentlicht: Das Repository enthält Skripte und Binär-Releases, ohne Lizenz. 2 % Dev-Gebühr, 0 % bei ninjaraider.
  • 35 ForgeMiner ↗ gpunvidiawindowshiveosclosed source Multi-Coin-GPU-Miner mit BTX-Unterstützung (MatMul v4.7 seit Version 1.6.0); das BTX-Beispiel nutzt BTX Pool. BTX läuft nur auf NVIDIA-Karten. Hinweis: Closed Source (laut README). 2 % Dev-Gebühr auf BTX.
  • 36 Solo mining helpers (btxd) ↗ soloofficialopen sourcescripts Offizielle Skripte für Solo-Mining gegen den eigenen btxd: eine Mining-Schleife mit Zustandsprüfung, Start- und Stopp-Skripte und ein Wallet-Backup. Für größere Setups verweist das README auf getblocktemplate mit externen Minern. Hinweis: Mining braucht eine zugelassene GPU und einen Node, der Blöcke selbst prüft (matmulvalidation=consensus, die Voreinstellung), keinen Trusted Mirror. Siehe das GPU-Betreiber-Runbook.

Node-Werkzeuge 5

  • 37 easynode ↗ desktopopen source Open-Source-Desktop-App (MIT) des easyBTX-Teams, die btxd auf dem eigenen Rechner installiert und überwacht. Hinweis: Läuft mit v0.34.15 ohne Modellnetz. Ohne zugelassene GPU folgt der Node den Prüfungen der Signer, statt die MatMul-Arbeit selbst zu prüfen.
  • 38 BTX Node Guardian ↗ scriptwatchdog Kostenloses Skript, das ein wartendes Netz von einem hängenden Node unterscheidet und hilfreiche Peers anwählt. Es startet den Node nie neu.
  • 39 BTX snapshots ↗ snapshotsignedpruned Täglicher Datadir-Snapshot (pruned), von einem zweiten Node geprüft und signiert. Auf einem Trusted Mirror gebaut: Die MatMul-Arbeit wurde anhand der Bestätigungen von Signern akzeptiert. Hinweis: Vor der Nutzung Signatur und SHA-256 prüfen. Nicht für Signer.
  • 40 Node help ↗ helpstuck heights Bekannte Hänge-Höhen mit Ursache und Lösung.
  • 41 AInode ↗ macmodel networkdesktop Mac-App (Apple Silicon, ab macOS 13) des easyBTX-Teams, die offene KI-Modelle über das BTX-Modellnetz lädt und auf dem eigenen Mac ausführt. Sie lädt nur herunter; sie stellt nichts bereit, zahlt nichts und verdient nichts. Hinweis: MIT-lizenziert; dieses Repository enthält nur die Downloads und Release-Notes. Die bei jedem Release angegebene SHA-256 vergleichen.

Wallets 4

Vorsicht: Von uns nicht geprüft. Wallets nur über den Link hier installieren, den Seed offline aufbewahren und nie auf einer Website eingeben.

  • 42 BTX Wallet ↗ officialbrowserpq Offizielle Post-Quanten-Wallet im Browser. Hinweis: Die Sicherungsdatei (.btxwallet) enthält den Seed im Klartext. Offline aufbewahren und nie an jemanden schicken.
  • 43 Node wallet (btx-qt, btx-cli) ↗ officialdesktopopen sourcepq Die Wallet in den offiziellen Releases für Linux und macOS: die Desktop-App btx-qt oder btxd mit btx-cli. Open Source; sie läuft auf dem eigenen Node. Hinweis: Die ganze Wallet mit backupwalletbundlearchive sichern (eine mit Passphrase verschlüsselte Datei; siehe doc/managing-wallets.md), nicht nur den Seed. Ein .btxwallet-Export enthält den Seed im Klartext.
  • 44 BTX PQ Wallet ↗ desktoppqmacwindows Post-Quanten-Desktop-Wallet des easyBTX-Teams für macOS und Windows. Hinweis: Frühe Testversion: interne Sicherheitsprüfung, kein unabhängiges Audit; der Quellcode ist nicht öffentlich und die direkten Downloads sind unsigniert. Ein Master-Key mit 64 Zeichen ist das einzige Backup; offline aufbewahren.
  • 45 Bonuz ↗ mobileiosandroidseedless Mobile Wallet ohne Seed für iOS und Android, mit BTX-Unterstützung. Hinweis: Seedless heißt: Es gibt keine Seed-Phrase, die man selbst sichert; Zugang und Wiederherstellung laufen über das Bonuz-Login. Vor dem Einsatz prüfen, wie die Wiederherstellung funktioniert.

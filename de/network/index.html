    Entwicklung der Node-Software

    btxchain/btx auf GitHub ↗

    Commits und Pull Requests in btxchain/btx, der Referenz-Implementierung des BTX-Nodes. GitHub öffnet das Repository auf main, dem Standard-Branch; die anderen Zeilen sind die Branches mit den jüngsten Commits. main enthält das letzte volle Release; die laufende Arbeit passiert auf den Release- und Review-Branches.

    Diese Messung ist älter als drei Stunden; die Zahlen können veraltet sein.

    Branch Letzter Commit Commits, 30 Tage

    Commits werden je Branch nach Commit-Datum gezählt, höchstens 100 pro Branch (angezeigt als 100+). Ein Commit, der auf mehreren Branches liegt, zählt bei jedem davon.

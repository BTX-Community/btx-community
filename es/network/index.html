    Desarrollo del software del nodo

    btxchain/btx en GitHub ↗

    Commits y pull requests en btxchain/btx, la implementación de referencia del nodo BTX. GitHub abre el repositorio en main, la rama por defecto; las demás filas son las ramas con los commits más recientes. main contiene la última versión completa; el trabajo actual se hace en las ramas de versión y de revisión.

    Esta medición tiene más de tres horas; las cifras pueden estar desactualizadas.

    Rama Último commit Commits, 30 días

    Los commits se cuentan por rama según su fecha, como máximo 100 por rama (se muestra 100+). Un commit que está en varias ramas cuenta en cada una de ellas.

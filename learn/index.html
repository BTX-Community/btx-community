Learn about BTX

What BTX is, and what the next release brings.

What is BTX?

Fixed supply

At most 21 million BTX, as with Bitcoin. A block comes about every 90 seconds; its reward of 20 BTX halves every 525,000 blocks, roughly every 18 months.

Source ↗

Mining by matrix multiplication

Instead of hashing, miners multiply large matrices, the work AI accelerators are built for. Since block 185,000 a node that checks blocks itself replays each one exactly on a qualified NVIDIA (CUDA) or Apple (Metal) GPU; nodes without one follow signed checks from others. There is no CPU mining.

Source ↗

Post-quantum signatures

Coins are locked with signatures meant to withstand quantum computers: ML-DSA-44 (NIST FIPS 204) for everyday spending, SLH-DSA (FIPS 205) as a hash-based fallback. These P2MR addresses start with btx1z.

Source ↗

Built on Bitcoin Knots

The node derives from Bitcoin Knots v29.2, a variant of Bitcoin Core. btxd, btx-cli, the RPC interface and PSBTs work the way Bitcoin users know them; what differs is the proof-of-work, the signatures and some network rules.

Source ↗

New in pre-release v0.34.16

Pre-release since 7 November 2026, Linux x86_64 only. It packages the 0.35 review branches; the 0.35 line stays open. The developers say it is not a release qualification. The current full release stays v0.34.15.

Presigned swap claims from the wallet

Since 0.34.13 a swap claim can be signed at funding and completed later by anyone who has the secret. htlc_presign and p2mr_leaf turn the hand-built transactions into a wallet step. The fee is fixed when you presign, and the claim must confirm before the refund height.

Source ↗

Model network with fewer open ports

The network for AI models is on by default and listens on TCP 29447. v0.34.16 no longer opens that port with -listen=0 or a proxy, finds model peers on the local network over UDP 29448, and adds a local security guard. -modelnet=0 turns all of it off; it does not spend coins.

Source ↗

Auto-update off behind a proxy

A node behind a proxy, or with -onlynet excluding IPv4 and IPv6, no longer checks for updates by default. Every other mainnet node still polls btx.dev and installs a newer signed release by itself unless autoupdateseamless=0.

Source ↗

Atlas, a second desktop app

The Linux archive adds btx-atlas beside btx-qt, which stays. Atlas needs glibc 2.39, WebKitGTK 4.1, GTK 3, the Ayatana tray library and zenity. btx-qt and ZeroMQ were already in v0.34.15.

Source ↗

Clearer backup warning

Wallet bundle backups now say that the descriptor file inside spends without the wallet passphrase, and warn for an encrypted wallet. Backups made with earlier versions hold the same file.

Source ↗

Before you switch

  • No CUDA, macOS or Windows archive. A GPU, mining or signing node on v0.34.16 loses its GPU path; those nodes stay on v0.34.15.
  • btx-qt in this archive needs glibc 2.43 and does not start on Ubuntu 24.04 or Debian 13; btxd and btx-cli need 2.38.
  • Unpack the whole archive and run bin/btxd from it. A bin/btxd copied on its own exits.
  • A sync from genesis still stops at block 126,978 (#272). Start from a snapshot.

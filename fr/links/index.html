Logiciels de minage 5

  • 32 easyBTX ↗ gpumaclinuxwslclosed source Appli de minage en un clic avec un portefeuille non dépositaire intégré, pour les Mac Apple Silicon et Linux (sous Windows via WSL). Remarque: Code source fermé ; les builds ne sont pas signés, vérifiez donc le SHA-256 sur la page de la version. Elle démarre par défaut sur BTX Pool. Des frais de développement de 5 % étaient indiqués pour elle en août 2026 ; vérifiez les frais actuels dans l'appli.
  • 33 matador ↗ gpunvidiaopen source Logiciel de minage GPU open source (NVIDIA, CUDA), en solo contre votre propre nœud ou dans un pool. Remarque: Dernière modification le 2026-08-21. Le démarrage rapide de son README contient une adresse de paiement d'exemple et deux pools hors ligne (minebtx, Byron) ; remplacez-les tous les trois. 1 % de frais de développement en mode pool ; il se met à jour lui-même sauf s'il est lancé avec --no-auto-update. NVIDIA Ampere (série RTX 30) ou plus récent uniquement.
  • 34 nekominer ↗ gpunvidialinuxhiveosclosed source Logiciel de minage NVIDIA (CUDA) pour plusieurs cryptomonnaies ; BTX tourne sous l'algorithme btxv4, la preuve de travail en vigueur depuis le bloc 185 000. Son README contient des commandes pour ninjaraider et BTX Pool. Remarque: Le code source du logiciel de minage n'est pas publié : le dépôt contient des scripts et des versions binaires, sans licence. 2 % de frais de développement, 0 % sur ninjaraider.
  • 35 ForgeMiner ↗ gpunvidiawindowshiveosclosed source Logiciel de minage GPU multi-cryptomonnaies compatible BTX (MatMul v4.7 depuis la version 1.6.0) ; son exemple BTX utilise BTX Pool. BTX ne se mine que sur des cartes NVIDIA. Remarque: Code source fermé (indiqué dans son README). 2 % de frais de développement sur BTX.
  • 36 Solo mining helpers (btxd) ↗ soloofficialopen sourcescripts Scripts officiels pour miner en solo contre votre propre btxd : une boucle de minage qui tient compte de l'état de santé, des scripts de démarrage et d'arrêt et une sauvegarde du portefeuille. Pour des installations plus grandes, le README renvoie à getblocktemplate avec des logiciels de minage externes. Remarque: Le minage exige un GPU qualifié et un nœud qui vérifie lui-même les blocs (matmulvalidation=consensus, la valeur par défaut), pas un miroir de confiance. Voir le guide d'exploitation GPU.

Outils pour nœuds 5

  • 37 easynode ↗ desktopopen source Application de bureau open source (MIT) de l'équipe easyBTX qui installe et supervise btxd sur la machine que vous avez déjà. Remarque: Fonctionne avec la v0.34.15 sans le réseau de modèles. Sans GPU qualifié, le nœud suit les vérifications des signataires au lieu de vérifier lui-même le travail MatMul.
  • 38 BTX Node Guardian ↗ scriptwatchdog Script gratuit qui distingue un réseau en attente d'un nœud bloqué et contacte des pairs utiles. Il ne redémarre jamais le nœud.
  • 39 BTX snapshots ↗ snapshotsignedpruned Instantané quotidien d'un répertoire de données élagué, vérifié et signé par un second nœud. Produit sur un miroir de confiance : le travail MatMul a donc été accepté sur la base des attestations des signataires. Remarque: Vérifiez la signature et le SHA-256 avant usage. Pas pour les signataires.
  • 40 Node help ↗ helpstuck heights Hauteurs de blocage connues, avec leur cause et leur solution.
  • 41 AInode ↗ macmodel networkdesktop Appli Mac (Apple Silicon, macOS 13 ou plus récent) de l'équipe easyBTX qui récupère des modèles d'IA ouverts via le réseau de modèles BTX et les exécute sur votre Mac. Elle ne fait que télécharger ; elle ne distribue, ne paie et ne gagne jamais rien. Remarque: Sous licence MIT ; ce dépôt ne contient que les téléchargements et les notes de version. Comparez le SHA-256 indiqué pour chaque version.

Portefeuilles 4

Attention: Non audités par nous. N'installez des portefeuilles que depuis le lien indiqué ici, gardez votre phrase de récupération hors ligne et ne la saisissez jamais sur un site web.

  • 42 BTX Wallet ↗ officialbrowserpq Portefeuille post-quantique officiel dans le navigateur. Remarque: Son fichier de sauvegarde (.btxwallet) contient la phrase de récupération en clair. Gardez-le hors ligne et ne l'envoyez jamais à personne.
  • 43 Node wallet (btx-qt, btx-cli) ↗ officialdesktopopen sourcepq Le portefeuille des versions officielles pour Linux et macOS : l'application de bureau btx-qt, ou btxd avec btx-cli. Open source ; il fonctionne sur votre propre nœud. Remarque: Sauvegardez le portefeuille entier avec backupwalletbundlearchive (un seul fichier chiffré avec une phrase secrète ; voir doc/managing-wallets.md), pas seulement la phrase de récupération. Un export .btxwallet contient la phrase de récupération en clair.
  • 44 BTX PQ Wallet ↗ desktoppqmacwindows Portefeuille de bureau post-quantique de l'équipe easyBTX pour macOS et Windows. Remarque: Version de test préliminaire : revue de sécurité interne, pas d'audit indépendant ; le code source n'est pas public et les téléchargements directs ne sont pas signés. Une clé maîtresse de 64 caractères est la seule sauvegarde ; gardez-la hors ligne.
  • 45 Bonuz ↗ mobileiosandroidseedless Portefeuille mobile sans phrase de récupération pour iOS et Android, compatible BTX. Remarque: « Sans phrase de récupération » veut dire qu'il n'y a pas de phrase de récupération à sauvegarder vous-même ; l'accès et la récupération passent par la connexion Bonuz. Vérifiez comment fonctionne la récupération avant de vous y fier.

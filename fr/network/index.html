    Développement du logiciel de nœud

    btxchain/btx sur GitHub ↗

    Commits et pull requests dans btxchain/btx, l'implémentation de référence du nœud BTX. GitHub ouvre le dépôt sur main, la branche par défaut ; les autres lignes sont les branches avec les commits les plus récents. main contient la dernière version complète ; le travail en cours se fait sur les branches de version et de revue.

    Cette mesure date de plus de trois heures ; les chiffres peuvent être dépassés.

    Branche Dernier commit Commits, 30 jours

    Les commits sont comptés par branche selon leur date, au plus 100 par branche (affiché 100+). Un commit présent sur plusieurs branches compte pour chacune d'elles.

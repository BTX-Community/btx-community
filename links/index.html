    Official 15
    • 01 btx.dev ↗ docswallet Official website with documentation, the browser wallet and the whitepaper. Note Last updated for v0.33.2 (August 2026); newer releases are on the GitHub releases page.
    • 02 BTX Node ↗ sourcenode Source code and releases of the reference node (btxd).
    • 03 The Protocol of Record ↗ whitepaperpdf The official whitepaper, describing what BTX is and why. Note Written for v0.33.2 (August 2026). Newer releases differ in places.
    • 04 BTX Specification ↗ specpdf The official technical specification of the protocol. Note Written for v0.33.2 (August 2026). Newer releases differ in places.
    • 05 Build from source ↗ docsnode How to build btxd yourself on Linux, if you would rather not trust a binary. Note A default build has no GPU support and cannot check MatMul blocks itself: add CUDA, or run it as a trusted mirror. On Ubuntu 22.04 or 24.04 add -DWITH_MODELNET=OFF, unless you install OpenSSL 3.5 or newer.
    • 06 Build on Windows 11 ↗ docswindowsnode Official step-by-step guide to building btxd and btx-cli on Windows 11. Note The current release has no official Windows archive. The handbook starts without CUDA, and such a build cannot check MatMul blocks itself: run it as a trusted mirror.
    • 07 Post-quantum signatures ↗ specpq ML-DSA and SLH-DSA in BTX, P2MR outputs and the address format.
    • 08 Post-quantum multisig ↗ docspq Step-by-step guide to a multisig wallet with post-quantum keys.
    • 09 Key management and backups ↗ docswalletbackup Official guide to wallet roles, multisig, timelocked recovery, watch-only setups and encrypted backups, with a restore drill.
    • 10 Browser wallet and node wallet ↗ docswalletbrowser Official guide to moving a btx.dev browser wallet into btxd and back, and how that file differs from an encrypted node backup. Note A .btxwallet file holds the post-quantum seed in plain text. Treat it like a private key and delete temporary copies.
    • 11 MatMul proof-of-work ↗ specmining How mining by matrix multiplication works and how blocks are checked. Note Describes MatMul v4.7, which the network runs since block 185,000, and keeps v3 as reference. Last updated 4 Aug 2026; its release notes still name v0.33.2.
    • 12 Trusted MatMul mirrors ↗ docsnode Running a node without a qualified GPU by trusting signers' replay attestations, and what that trust means. Note On mainnet it needs at least two pinned signers and a threshold of two. Pin only signers that are live today.
    • 13 Who needs a GPU ↗ docsnodegpu Official explanation of why a node needs a qualified GPU to check blocks itself since block 185,000, and what machines without one can do.
    • 14 Exchange and custody integration (BCP/1) ↗ docsexchangecustody Official integration profile for exchanges and custodians: UTXO model, watch-only setup, deposits, confirmations and reorg handling.
    • 15 Report a security problem ↗ security How to report a vulnerability privately to the BTX Development Team. Not for support questions.

    Pools 2
    • 01 ninjaraider ↗ poolmulti-coin Multi-coin pool with BTX. Check its fee on the pool page. Note Miners log in as ADDRESS.worker; nekominer documents this and charges no dev fee on this pool.
    • 02 BTX Pool ↗ pool Pool dedicated to BTX, run by the author of btx-pool-miner (GitHub lucasan123). It pays miners inside each block it finds, split by work over a 30-minute window. Check its fee on the pool page.

    Miners 5
    • 01 easyBTX ↗ gpumaclinuxwslclosed source One-click miner app with a self-custodial wallet built in, for Apple Silicon Macs and Linux (on Windows through WSL). Note Closed source; the builds are unsigned, so check the SHA-256 on the release page. It starts on BTX Pool by default. A 5% dev fee was listed for it in August 2026; check the current fee in the app.
    • 02 matador ↗ gpunvidiaopen source Open-source GPU miner (NVIDIA, CUDA), solo against your own node or in a pool. Note Last change 2026-08-21. The quick start in its README contains a sample payout address and two offline pools (minebtx, Byron); replace all three. 1% dev fee in pool mode; it updates itself unless started with --no-auto-update. NVIDIA Ampere (RTX 30 series) or newer only.
    • 03 nekominer ↗ gpunvidialinuxhiveosclosed source NVIDIA (CUDA) miner for several coins; BTX runs as algorithm btxv4, the proof-of-work since block 185,000. Its README has commands for ninjaraider and BTX Pool. Note The miner's source is not published: the repository holds scripts and binary releases, with no licence. 2% dev fee, 0% on ninjaraider.
    • 04 ForgeMiner ↗ gpunvidiawindowshiveosclosed source Multi-coin GPU miner with BTX support (MatMul v4.7 since version 1.6.0); its BTX example uses BTX Pool. BTX mines on NVIDIA cards only. Note Closed source (stated in its README). 2% dev fee on BTX.
    • 05 Solo mining helpers (btxd) ↗ soloofficialopen sourcescripts Official scripts for solo mining against your own btxd: a health-aware mining loop, start and stop scripts and a wallet backup. For larger setups the README points to getblocktemplate with external miners. Note Mining needs a qualified GPU and a node that checks blocks itself (matmulvalidation=consensus, the default), not a trusted mirror. See the GPU operator runbook.

    Node tools 7
    • 01 easynode ↗ desktopopen source Open-source (MIT) desktop app of the easyBTX team that installs and supervises btxd on the machine you already own. Note Runs v0.34.15 without the model network. Without a qualified GPU the node follows signers' checks instead of checking the MatMul work itself.
    • 02 BTX Node Guardian ↗ scriptwatchdog Free script that tells a waiting network from a stuck node and dials helpful peers. It never restarts the node.
    • 03 BTX snapshots ↗ snapshotsignedpruned Daily pruned datadir snapshot, checked and signed by a second node. Built on a trusted mirror, so the MatMul work was accepted on signers' attestations. Note Verify the signature and SHA-256 before use. Not for signers.
    • 04 easyBTX UTXO snapshots ↗ snapshotutxosigned UTXO snapshot for loadtxoutset, confirmed by two operators, with SHA-256 of the file and the manifest. Note Check the SHA-256 before use. The JSON names the height; it can lag the chain by a few thousand blocks.
    • 05 Byron Bay UTXO snapshots ↗ snapshotutxo UTXO snapshot every 1,000 blocks from the Byron Bay archive node, with SHA256SUMS; the last seven are kept. Note One signer, the operator. A height is sometimes skipped; then there is no file, not a wrong one.
    • 06 Node help ↗ helpstuck heights Known stuck heights with their cause and fix.
    • 07 AInode ↗ macmodel networkdesktop Mac app (Apple Silicon, macOS 13 or later) of the easyBTX team that fetches open AI models over the BTX model network and runs them on your Mac. It only downloads; it never serves, pays or earns. Note MIT-licensed; this repository holds only the downloads and release notes. Compare the SHA-256 listed with each release.

    Wallets 4

    Caution: Not audited by us. Only install wallets from the link here, keep your seed offline and never type it into a website.

    • 01 BTX Wallet ↗ officialbrowserpq Official post-quantum wallet in the browser. Note Its backup file (.btxwallet) holds the seed in plain text. Keep it offline and never send it to anyone.
    • 02 Node wallet (btx-qt, btx-cli) ↗ officialdesktopopen sourcepq The wallet in the official releases: btxd with btx-cli, open source, on your own node. The desktop app btx-qt is in v0.34.15; the v0.34.16 archives leave it out. Note Back up the whole wallet with backupwalletbundlearchive (one passphrase-encrypted file; see doc/managing-wallets.md), not only the seed. A .btxwallet export holds the seed in plain text.
    • 03 BTX PQ Wallet ↗ desktoppqmacwindowslinux Post-quantum desktop wallet of the easyBTX team for macOS, Windows and Linux. Note No independent audit; the source code is not public. The Mac build is signed and notarized (Bonuz Technology DMCC); Windows and Linux builds are unsigned, so check the SHA-256. Keep the master key or the encrypted recovery file offline.
    • 04 Bonuz ↗ mobileiosandroidseedless Seedless mobile wallet for iOS and Android with BTX support. Note Seedless means there is no seed phrase you back up yourself: the page says the key is split by MPC, and access and recovery go through the Bonuz login. Check how recovery works before you rely on it.

    Buying BTX 1

    Caution: There is no exchange for BTX. These are trades from person to person without escrow: you pay first and rely on the seller. Not checked by us. Read the checklist "Before you buy or receive BTX" on the start page first, and start with a small amount.

    • 01 easyBTX seller board ↗ p2ptelegramno escrow Sellers the easyBTX team says it has bought from itself. You agree amount and price with a seller on Telegram and pay them directly, usually in USDT. Note easyBTX says it holds no funds, is not a party to any trade and quotes no price. On 16 November 2026 the board listed one seller. Contact a seller only through the link on easyBTX's own page. Anyone who messages you first is not that seller. A price agreed there is not a market price.

    Bridges and testnets 4

    Caution: Experimental and not audited by us. Bridges can lose funds; do not send more than you can afford to lose.

    • 01 wBTX specification (official) ↗ officialspecwrappedethereum The developers' design for wrapped BTX on EVM chains: token rules, bridge models and reference contracts. A design, not a working bridge. Note Not launched. Its launch checklist is still open and the reference contracts are unaudited.
    • 02 WBTX (wbtx-eth) ↗ ethereumwrappedtestnet Wrapped BTX on Ethereum - contracts, validator services and a local simulator, by the GitHub organisation evxdev. Testnet only. Note Last change 2026-07-09.
    • 03 btx.supply ↗ testnetbridgewip Public tester site and guide of the wbtx-eth project (evxdev): a WBTX bridge on an Ethereum testnet. Test tokens have no value. Note Testnet only; it can be reset. Code unchanged since 2026-07-09.
    • 04 Robinhood Chain testnet ↗ testnetbridgewip The same WBTX test bridge as btx.supply, on the Robinhood Chain testnet. Test tokens have no value. Note Testnet only; it can be reset. Code unchanged since 2026-07-09.

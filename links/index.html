Official 15

  • 09 btx.dev ↗ docswallet Official website with documentation, the browser wallet and the whitepaper. Note: Last updated for v0.33.2 (August 2026); newer releases are on the GitHub releases page.
  • 10 BTX Node ↗ sourcenode Source code and releases of the reference node (btxd).
  • 11 The Protocol of Record ↗ whitepaperpdf The official whitepaper, describing what BTX is and why. Note: Written for v0.33.2 (August 2026). Newer releases differ in places.
  • 12 BTX Specification ↗ specpdf The official technical specification of the protocol. Note: Written for v0.33.2 (August 2026). Newer releases differ in places.
  • 13 Build from source ↗ docsnode How to build btxd yourself on Linux, if you would rather not trust a binary. Note: A default build has no GPU support and cannot check MatMul blocks itself: add CUDA, or run it as a trusted mirror. On Ubuntu 22.04 or 24.04 add -DWITH_MODELNET=OFF, unless you install OpenSSL 3.5 or newer.
  • 14 Build on Windows 11 ↗ docswindowsnode Official step-by-step guide to building btxd and btx-cli on Windows 11. Note: The current release has no official Windows archive. The handbook starts without CUDA, and such a build cannot check MatMul blocks itself: run it as a trusted mirror.
  • 15 Post-quantum signatures ↗ specpq ML-DSA and SLH-DSA in BTX, P2MR outputs and the address format.
  • 16 Post-quantum multisig ↗ docspq Step-by-step guide to a multisig wallet with post-quantum keys.
  • 17 Key management and backups ↗ docswalletbackup Official guide to wallet roles, multisig, timelocked recovery, watch-only setups and encrypted backups, with a restore drill.
  • 18 Browser wallet and node wallet ↗ docswalletbrowser Official guide to moving a btx.dev browser wallet into btxd and back, and how that file differs from an encrypted node backup. Note: A .btxwallet file holds the post-quantum seed in plain text. Treat it like a private key and delete temporary copies.
  • 19 MatMul proof-of-work ↗ specmining How mining by matrix multiplication works and how blocks are checked. Note: The file is marked historical: it records the v3 design. Since block 185,000 the network runs MatMul v4.7.
  • 20 Trusted MatMul mirrors ↗ docsnode Running a node without a qualified GPU by trusting signers' replay attestations, and what that trust means. Note: On mainnet it needs at least two pinned signers and a threshold of two. Pin only signers that are live today.
  • 21 Who needs a GPU ↗ docsnodegpu Official explanation of why a node needs a qualified GPU to check blocks itself since block 185,000, and what machines without one can do.
  • 22 Exchange and custody integration (BCP/1) ↗ docsexchangecustody Official integration profile for exchanges and custodians: UTXO model, watch-only setup, deposits, confirmations and reorg handling.
  • 23 Report a security problem ↗ security How to report a vulnerability privately to the BTX Development Team. Not for support questions.

Pools 2

  • 30 ninjaraider ↗ poolmulti-coin Multi-coin pool with BTX. Check its fee on the pool page. Note: Miners log in as ADDRESS.worker; nekominer documents this and charges no dev fee on this pool.
  • 31 BTX Pool ↗ pool Pool dedicated to BTX, run by the author of btx-pool-miner (GitHub lucasan123). It pays miners inside each block it finds, split by work over a 30-minute window. Check its fee on the pool page.

Miners 5

  • 32 easyBTX ↗ gpumaclinuxwslclosed source One-click miner app with a self-custodial wallet built in, for Apple Silicon Macs and Linux (on Windows through WSL). Note: Closed source; the builds are unsigned, so check the SHA-256 on the release page. It starts on BTX Pool by default. A 5% dev fee was listed for it in August 2026; check the current fee in the app.
  • 33 matador ↗ gpunvidiaopen source Open-source GPU miner (NVIDIA, CUDA), solo against your own node or in a pool. Note: Last change 2026-08-21. The quick start in its README contains a sample payout address and two offline pools (minebtx, Byron); replace all three. 1% dev fee in pool mode; it updates itself unless started with --no-auto-update. NVIDIA Ampere (RTX 30 series) or newer only.
  • 34 nekominer ↗ gpunvidialinuxhiveosclosed source NVIDIA (CUDA) miner for several coins; BTX runs as algorithm btxv4, the proof-of-work since block 185,000. Its README has commands for ninjaraider and BTX Pool. Note: The miner's source is not published: the repository holds scripts and binary releases, with no licence. 2% dev fee, 0% on ninjaraider.
  • 35 ForgeMiner ↗ gpunvidiawindowshiveosclosed source Multi-coin GPU miner with BTX support (MatMul v4.7 since version 1.6.0); its BTX example uses BTX Pool. BTX mines on NVIDIA cards only. Note: Closed source (stated in its README). 2% dev fee on BTX.
  • 36 Solo mining helpers (btxd) ↗ soloofficialopen sourcescripts Official scripts for solo mining against your own btxd: a health-aware mining loop, start and stop scripts and a wallet backup. For larger setups the README points to getblocktemplate with external miners. Note: Mining needs a qualified GPU and a node that checks blocks itself (matmulvalidation=consensus, the default), not a trusted mirror. See the GPU operator runbook.

Node tools 5

  • 37 easynode ↗ desktopopen source Open-source (MIT) desktop app of the easyBTX team that installs and supervises btxd on the machine you already own. Note: Runs v0.34.15 without the model network. Without a qualified GPU the node follows signers' checks instead of checking the MatMul work itself.
  • 38 BTX Node Guardian ↗ scriptwatchdog Free script that tells a waiting network from a stuck node and dials helpful peers. It never restarts the node.
  • 39 BTX snapshots ↗ snapshotsignedpruned Daily pruned datadir snapshot, checked and signed by a second node. Built on a trusted mirror, so the MatMul work was accepted on signers' attestations. Note: Verify the signature and SHA-256 before use. Not for signers.
  • 40 Node help ↗ helpstuck heights Known stuck heights with their cause and fix.
  • 41 AInode ↗ macmodel networkdesktop Mac app (Apple Silicon, macOS 13 or later) of the easyBTX team that fetches open AI models over the BTX model network and runs them on your Mac. It only downloads; it never serves, pays or earns. Note: MIT-licensed; this repository holds only the downloads and release notes. Compare the SHA-256 listed with each release.

Wallets 4

Caution: Not audited by us. Only install wallets from the link here, keep your seed offline and never type it into a website.

  • 42 BTX Wallet ↗ officialbrowserpq Official post-quantum wallet in the browser. Note: Its backup file (.btxwallet) holds the seed in plain text. Keep it offline and never send it to anyone.
  • 43 Node wallet (btx-qt, btx-cli) ↗ officialdesktopopen sourcepq The wallet in the official releases for Linux and macOS: the desktop app btx-qt, or btxd with btx-cli. Open source; it runs on your own node. Note: Back up the whole wallet with backupwalletbundlearchive (one passphrase-encrypted file; see doc/managing-wallets.md), not only the seed. A .btxwallet export holds the seed in plain text.
  • 44 BTX PQ Wallet ↗ desktoppqmacwindows Post-quantum desktop wallet of the easyBTX team for macOS and Windows. Note: Early test build: internal security review, no independent audit; the source code is not public and the direct downloads are unsigned. A 64-character master key is the only backup; keep it offline.
  • 45 Bonuz ↗ mobileiosandroidseedless Seedless mobile wallet for iOS and Android with BTX support. Note: Seedless means there is no seed phrase you back up yourself; access and recovery go through the Bonuz login. Check how recovery works before you rely on it.

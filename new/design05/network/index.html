    Key to the board

    What the values mean

    What each value on the board shows, in the order the board lists them.

    The chain

    Status
    The status page's overall reading of the network, top right of the board: Normal, Degraded or Incident. It reads Loading until the first answer arrives, and No data if the board could not load the data or the data is out of date. The status page lists the checks behind it.
    Block height
    The number of the newest block, counted from the first one. It goes up by one with every new block.
    Last block
    How long ago the newest block was found. The bar under it empties over 90 seconds, the average time between blocks; some blocks take longer.
    Average block time, 24 h
    The average gap between blocks over the last 24 hours. The chain aims for 90 seconds.
    Latest node release
    The newest published version of the node software (on the home page: Latest release). Download it only from the releases page on GitHub ↗ (opens another site).
    Nodes on it
    How many reachable nodes run that release, out of all reachable nodes the status page counted (on the home page: Nodes running it).
    Active signers
    Machines with a qualified GPU that check the MatMul work of new blocks and sign the result. Nodes without such a GPU (trusted mirrors) rely on them.
    Stable, Performant, Secure
    The status page's three summary verdicts: does the chain hold steady, do blocks come on time, is mining spread widely enough. Each reads OK, Watch, Problem or Unknown.

    BTX in numbers

    Mined so far
    All BTX created by block rewards up to now.
    Share of the 21 million maximum
    What has been mined, as a share of the 21 million BTX that can ever exist.
    Block reward
    New BTX paid to whoever mines a block. It halves every 525,000 blocks.
    Next halving
    Blocks left until the reward halves.
    Time to the halving
    Roughly how long those blocks take, at 90 seconds each.
    Transactions, 24 h
    Transactions in the blocks of the last 24 hours.
    Size of the chain
    The disk space the whole chain takes on a node.

    The rest of the board

    Data from
    When the status page last read the network. If the data is out of date, the values may be wrong, and the board says so.
    Network upgrade ahead
    Shown only when a rule change is scheduled, with its block and the blocks to go. Every node and miner needs a release that knows the change before then, or it stops following the network. Releases and release notes ↗ (opens another site)
    Pause
    The button at the bottom right stops the board from changing while you read. Press it again to see the newest data.

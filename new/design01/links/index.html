Pools 2

  • ninjaraider ↗

    ninjaraider.com

    Multi-coin pool with BTX. Check its fee on the pool page.

    Note Miners log in as ADDRESS.worker; nekominer documents this and charges no dev fee on this pool.

    poolmulti-coin

  • BTX Pool ↗

    btx-pool.com

    Pool dedicated to BTX, run by the author of btx-pool-miner (GitHub lucasan123). It pays miners inside each block it finds, split by work over a 30-minute window. Check its fee on the pool page.

    pool

Miners 5

  • easyBTX ↗

    easybtx.com

    One-click miner app with a self-custodial wallet built in, for Apple Silicon Macs and Linux (on Windows through WSL).

    Note Closed source; the builds are unsigned, so check the SHA-256 on the release page. It starts on BTX Pool by default. A 5% dev fee was listed for it in August 2026; check the current fee in the app.

    gpumaclinuxwslclosed source

  • matador ↗

    github.com

    Open-source GPU miner (NVIDIA, CUDA), solo against your own node or in a pool.

    Note Last change 2026-08-21. The quick start in its README contains a sample payout address and two offline pools (minebtx, Byron); replace all three. 1% dev fee in pool mode; it updates itself unless started with --no-auto-update. NVIDIA Ampere (RTX 30 series) or newer only.

    gpunvidiaopen source

  • nekominer ↗

    github.com

    NVIDIA (CUDA) miner for several coins; BTX runs as algorithm btxv4, the proof-of-work since block 185,000. Its README has commands for ninjaraider and BTX Pool.

    Note The miner's source is not published: the repository holds scripts and binary releases, with no licence. 2% dev fee, 0% on ninjaraider.

    gpunvidialinuxhiveosclosed source

  • ForgeMiner ↗

    github.com

    Multi-coin GPU miner with BTX support (MatMul v4.7 since version 1.6.0); its BTX example uses BTX Pool. BTX mines on NVIDIA cards only.

    Note Closed source (stated in its README). 2% dev fee on BTX.

    gpunvidiawindowshiveosclosed source

  • Solo mining helpers (btxd) ↗

    github.com

    Official scripts for solo mining against your own btxd: a health-aware mining loop, start and stop scripts and a wallet backup. For larger setups the README points to getblocktemplate with external miners.

    Note Mining needs a qualified GPU and a node that checks blocks itself (matmulvalidation=consensus, the default), not a trusted mirror. See the GPU operator runbook.

    soloofficialopen sourcescripts

Node tools 7

  • easynode ↗

    github.com

    Open-source (MIT) desktop app of the easyBTX team that installs and supervises btxd on the machine you already own.

    Note Runs v0.34.15 without the model network. Without a qualified GPU the node follows signers' checks instead of checking the MatMul work itself.

    desktopopen source

  • BTX Node Guardian ↗

    easybtx.com

    Free script that tells a waiting network from a stuck node and dials helpful peers. It never restarts the node.

    scriptwatchdog

  • BTX snapshots ↗

    github.com

    Daily pruned datadir snapshot, checked and signed by a second node. Built on a trusted mirror, so the MatMul work was accepted on signers' attestations.

    Note Verify the signature and SHA-256 before use. Not for signers.

    snapshotsignedpruned

  • easyBTX UTXO snapshots ↗

    easybtx.com

    UTXO snapshot for loadtxoutset, confirmed by two operators, with SHA-256 of the file and the manifest.

    Note Check the SHA-256 before use. The JSON names the height; it can lag the chain by a few thousand blocks.

    snapshotutxosigned

  • Byron Bay UTXO snapshots ↗

    api-explorer.btxbyronbay.com

    UTXO snapshot every 1,000 blocks from the Byron Bay archive node, with SHA256SUMS; the last seven are kept.

    Note One signer, the operator. A height is sometimes skipped; then there is no file, not a wrong one.

    snapshotutxo

  • Node help ↗

    network.btx-monitoring.com

    Known stuck heights with their cause and fix.

    helpstuck heights

  • AInode ↗

    github.com

    Mac app (Apple Silicon, macOS 13 or later) of the easyBTX team that fetches open AI models over the BTX model network and runs them on your Mac. It only downloads; it never serves, pays or earns.

    Note MIT-licensed; this repository holds only the downloads and release notes. Compare the SHA-256 listed with each release.

    macmodel networkdesktop

Wallets 4

Caution Not audited by us. Only install wallets from the link here, keep your seed offline and never type it into a website.

  • BTX Wallet ↗

    btx.dev

    Official post-quantum wallet in the browser.

    Note Its backup file (.btxwallet) holds the seed in plain text. Keep it offline and never send it to anyone.

    officialbrowserpq

  • Node wallet (btx-qt, btx-cli) ↗

    github.com

    The wallet in the official releases: btxd with btx-cli, open source, on your own node. The desktop app btx-qt is in v0.34.15; the v0.34.16 archives leave it out.

    Note Back up the whole wallet with backupwalletbundlearchive (one passphrase-encrypted file; see doc/managing-wallets.md), not only the seed. A .btxwallet export holds the seed in plain text.

    officialdesktopopen sourcepq

  • BTX PQ Wallet ↗

    pq-wallet.com

    Post-quantum desktop wallet of the easyBTX team for macOS, Windows and Linux.

    Note No independent audit; the source code is not public. The Mac build is signed and notarized (Bonuz Technology DMCC); Windows and Linux builds are unsigned, so check the SHA-256. Keep the master key or the encrypted recovery file offline.

    desktoppqmacwindowslinux

  • Bonuz ↗

    www.bonuz.xyz

    Seedless mobile wallet for iOS and Android with BTX support.

    Note Seedless means there is no seed phrase you back up yourself: the page says the key is split by MPC, and access and recovery go through the Bonuz login. Check how recovery works before you rely on it.

    mobileiosandroidseedless

Buying BTX 1

Caution There is no exchange for BTX. These are trades from person to person without escrow: you pay first and rely on the seller. Not checked by us. Read the checklist "Before you buy or receive BTX" on the start page first, and start with a small amount.

  • easyBTX seller board ↗

    easybtx.com

    Sellers the easyBTX team says it has bought from itself. You agree amount and price with a seller on Telegram and pay them directly, usually in USDT.

    Note easyBTX says it holds no funds, is not a party to any trade and quotes no price. On 16 November 2026 the board listed one seller. Contact a seller only through the link on easyBTX's own page. Anyone who messages you first is not that seller. A price agreed there is not a market price.

    p2ptelegramno escrow

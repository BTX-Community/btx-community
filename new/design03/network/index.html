    New in v0.34.16

    Checked 2026-11-16 Applies to v0.34.16

    A full release since 15 November 2026, first published on 7 November as a pre-release. Archives for Linux x86_64, with and without CUDA 13; none for macOS or Windows. It packages the 0.35 review branches; the 0.35 line stays open.

    Presigned swap claims from the wallet

    Since 0.34.13 a swap claim can be signed at funding and completed later by anyone who has the secret. htlc_presign and p2mr_leaf turn the hand-built transactions into a wallet step. The fee is fixed when you presign, and the claim must confirm before the refund height.

    Source: Presigned swap claims from the wallet ↗

    Cross-chain swaps, off by default

    SwapNet is built into btxd and starts only with -swapnet=1. Its keys for the other chains sit in the data directory: back them up with exportswaprecovery, not by copying files. Turning it off does not cancel a funded swap; refund deadlines keep running.

    Source: Cross-chain swaps, off by default ↗

    Model network with fewer open ports

    The network for AI models is on by default and listens on TCP 29447. v0.34.16 no longer opens that port with -listen=0 or a proxy, finds model peers on the local network over UDP 29448, and adds a local security guard. -modelnet=0 turns all of it off; it does not spend coins.

    Source: Model network with fewer open ports ↗

    Auto-update off behind a proxy

    A node behind a proxy, or with -onlynet excluding IPv4 and IPv6, no longer checks for updates by default. Every other mainnet node still polls btx.dev and installs a newer signed release by itself unless autoupdateseamless=0.

    Source: Auto-update off behind a proxy ↗

    Signing keeps your timelocks

    For a csv, cltv or refund leaf, v0.34.15 rewrote nLockTime, nSequence and version while signing. signrawtransactionwithwallet and walletprocesspsbt now refuse and name the value they need, unless adjust_timelocks is true.

    Source: Signing keeps your timelocks ↗

    Clearer backup warning

    Wallet bundle backups now say that the descriptor file inside spends without the wallet passphrase, and warn for an encrypted wallet. Backups made with earlier versions hold the same file.

    Source: Clearer backup warning ↗

    Before you switch

    • No macOS or Windows archive: a Mac node stays on v0.34.15. The CUDA archive is built for NVIDIA Blackwell (sm_120) and does not include the NVIDIA driver.
    • No desktop app: both archives leave out btx-qt and btx-atlas, which need a newer glibc than 2.38. Use btxd and btx-cli.
    • The archives were replaced several times under the same tag, last on 15 November 2026. The current ones bundle libevent, SQLite, ZeroMQ and libgomp; only libc, libstdc++ and the NVIDIA driver come from your system. Check your download against the release's SHA256SUMS.
    • Unpack the whole archive and run bin/btxd from it. A bin/btxd copied on its own exits.
    • A sync from genesis still stops at block 126,978 (#272). Start from a snapshot.

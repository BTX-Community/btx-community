    BTX fast lane

    Everything a newcomer needs on one page: what BTX is, how to get a wallet, buy, mine or run a node, and what to watch out for.

    The facts

    What it is

    A Bitcoin fork (Bitcoin Knots v29.2) with two changes: proof-of-work by matrix multiplication on GPUs, and post-quantum signatures.

    Source ↗

    Supply

    At most 21,000,000 BTX. 20 BTX per block, halving every 525,000 blocks (about 18 months).

    Source ↗

    Blocks

    One block about every 90 seconds; difficulty adjusts every block.

    Source ↗

    Addresses

    Start with btx1z. Signed with ML-DSA-44 (NIST FIPS 204), with SLH-DSA (FIPS 205) as a hash-based fallback.

    Source ↗

    Mining needs a GPU

    Since block 185,000 every block is replayed on a qualified NVIDIA (CUDA) or Apple (Metal) GPU. No CPU mining.

    Source ↗

    Current release

    v0.34.16, for Linux x86_64 only (CPU and CUDA builds). The last macOS build is v0.34.15 (Apple Silicon). There is no official Windows build.

    Source ↗

    The first million

    Blocks 1 to 50,000 paid 1,000,000 BTX (4.76 % of the maximum) to one address. All of it left through shielded transactions by May 2026; where it went cannot be seen.

    Source ↗

    No exchange

    No exchange lists this BTX. Trading is person to person or over the counter. The "BTX" on CoinGecko and similar sites is a different coin.

    Source ↗

      What do you want to do?

      Get a wallet

      Pick one. Write the recovery words on paper, never into a website or chat.

      1. PQ Wallet: desktop, macOS, Windows, Linux ↗
      2. Bonuz: phone, iOS and Android ↗
      3. BTX Wallet: in the browser, from btx.dev ↗
      4. Backups and keys: the official guide ↗

      Buy BTX

      There is no exchange and no escrow. You usually pay first and trust the seller.

      1. Read the checklist before you buy →
      2. easyBTX seller board: person to person, no escrow ↗
      3. Start with a small amount and wait for confirmations
      4. Anyone who messages you first is not a seller

      Mine

      You need a GPU (NVIDIA, AMD or Apple), mining software and a pool.

      1. easyBTX miner: macOS, Windows, Linux ↗
      2. matador: open source, NVIDIA ↗
      3. Pool: ninjaraider ↗
      4. Pool: BTX Pool ↗
      5. Two pools find almost every block. Check their shares before you pick one ↗

      Run a node

      Linux x86_64. Start from a snapshot instead of syncing from the first block.

      1. Download v0.34.16 and compare it with SHA256SUMS ↗
      2. Load the latest snapshot ↗
      3. Node holds coins or mines? Set modelnet=0, natpmp=0 and swapnet=0 ↗
      4. Updates install themselves by default; set autoupdate=0 to decide yourself
      5. Open TCP port 19335 for incoming peers
      6. Read the checklist before you install →

      Watch out

      • Nobody from the team or a seller will message you first. Treat every direct message as a scam.
      • Never type your recovery words or upload a wallet file into any website.
      • Release files have been replaced under the same version tag, and SHA256SUMS is not signed. Compare your download with it on the day you download.
      • The price on btxprice.com is a model price, not the result of exchange trades.

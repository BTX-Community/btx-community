Scam warning

Never share your seed phrase, your wallet backup file or your private key. Nobody from the community will ever ask for them. Direct messages offering help or “support” are scams.

  • BTX Community (Telegram) ↗ (opens another site) The main community group on Telegram, open to everyone. telegram chat →
  • BTX main chat (Telegram gate) ↗ (opens another site) Verification gate to the main BTX chat on compute and tech. It is not run by the community. For community questions, use the group above. telegram chat →
  • BTX on X ↗ (opens another site) Community account on X. x news →
  • BTX Chain on X ↗ (opens another site) Community-run account on X, not the developers'. It posted release notes and network news in August and September 2026. x news →
  • easyBTX chat ↗ (opens another site) Telegram group of the easyBTX team, for questions about its miner, node app and wallet. telegram support →

    Note Run by the vendor of those apps.

  • BTX.best ↗ (opens another site) Portal of the easyBTX team: explorer, wallet, mining and news in one place. portal news →

Official

15 links

  • btx.dev ↗ (opens another site) Official website with documentation, the browser wallet and the whitepaper. docs wallet →

    Note Last updated for v0.33.2 (August 2026). Newer releases are on the GitHub releases page ↗ (opens another site).

  • BTX Node ↗ (opens another site) Source code and releases of the reference node (btxd). source node →
  • The Protocol of Record ↗ (opens another site) The official whitepaper. It describes what BTX is and why. whitepaper pdf →

    Note Written for v0.33.2 (August 2026). Newer releases differ in places.

  • BTX Specification ↗ (opens another site) The official technical specification of the protocol. spec pdf →

    Note Written for v0.33.2 (August 2026). Newer releases differ in places.

  • Build from source ↗ (opens another site) How to build btxd yourself on Linux, if you would rather not trust a binary. docs node →

    Note A default build has no GPU support and cannot check MatMul blocks itself. Add CUDA, or run it as a trusted mirror. On Ubuntu 22.04 or 24.04, add -DWITH_MODELNET=OFF unless you install OpenSSL 3.5 or newer.

  • Build on Windows 11 ↗ (opens another site) Official step-by-step guide to building btxd and btx-cli on Windows 11. docs windows node →

    Note The current release has no official Windows archive. The handbook starts without CUDA, and such a build cannot check MatMul blocks itself: run it as a trusted mirror.

  • Post-quantum signatures ↗ (opens another site) ML-DSA and SLH-DSA in BTX, P2MR outputs and the address format. spec pq →
  • Post-quantum multisig ↗ (opens another site) Step-by-step guide to a multisig wallet with post-quantum keys. docs pq →
  • Key management and backups ↗ (opens another site) Official guide to wallet roles, multisig, timelocked recovery, watch-only setups and encrypted backups, with a restore drill. docs wallet backup →
  • Browser wallet and node wallet ↗ (opens another site) Official guide to moving a btx.dev browser wallet into btxd and back, and how that file differs from an encrypted node backup. docs wallet browser →

    Note A .btxwallet file holds the post-quantum seed in plain text. Treat it like a private key and delete temporary copies.

  • MatMul proof-of-work ↗ (opens another site) How mining by matrix multiplication works and how blocks are checked. spec mining →

    Note Describes MatMul v4.7, which the network has run since block 185,000, and keeps v3 as reference. Last updated 4 Aug 2026; its release notes still name v0.33.2.

  • Trusted MatMul mirrors ↗ (opens another site) How to run a node without a qualified GPU by trusting signers' replay attestations, and what that trust means. docs node →

    Note On mainnet it needs at least two pinned signers and a threshold of two. Pin only signers that are live today.

  • Who needs a GPU ↗ (opens another site) Official explanation of why a node needs a qualified GPU to check blocks itself since block 185,000, and what machines without one can do. docs node gpu →
  • Exchange and custody integration (BCP/1) ↗ (opens another site) Official integration profile for exchanges and custodians: UTXO model, watch-only setup, deposits, confirmations and reorg handling. docs exchange custody →
  • Report a security problem ↗ (opens another site) How to report a vulnerability privately to the BTX Development Team. Not for support questions. security →

  • ninjaraider explorer ↗ (opens another site) Block explorer run by the ninjaraider pool, with a JSON API for addresses and blocks. explorer api →

  • btxinfo ↗ (opens another site) Supply, holders and rich list. analytics rich list →

Miners

5 links

  • easyBTX ↗ (opens another site) One-click miner app with a self-custodial wallet built in, for Apple Silicon Macs and Linux (on Windows through WSL). gpu mac linux wsl closed source →

    Note Closed source. The builds are unsigned, so check the SHA-256 on the release page. It starts on BTX Pool by default. A 5% dev fee was listed for it in August 2026; check the current fee in the app.

  • matador ↗ (opens another site) Open-source GPU miner (NVIDIA, CUDA), solo against your own node or in a pool. gpu nvidia open source →

    Note Last change 2026-08-21. The quick start in its README contains a sample payout address and two offline pools (minebtx, Byron): replace all three. 1% dev fee in pool mode. It updates itself unless started with --no-auto-update. NVIDIA Ampere (RTX 30 series) or newer only.

  • nekominer ↗ (opens another site) NVIDIA (CUDA) miner for several coins. BTX runs as algorithm btxv4, the proof-of-work since block 185,000. Its README has commands for ninjaraider and BTX Pool. gpu nvidia linux hiveos closed source →

    Note The miner's source is not published: the repository holds scripts and binary releases, with no licence. 2% dev fee, 0% on ninjaraider.

  • ForgeMiner ↗ (opens another site) Multi-coin GPU miner with BTX support (MatMul v4.7 since version 1.6.0). Its BTX example uses BTX Pool. BTX mines on NVIDIA cards only. gpu nvidia windows hiveos closed source →

    Note Closed source (stated in its README). 2% dev fee on BTX.

  • Solo mining helpers (btxd) ↗ (opens another site) Official scripts for solo mining against your own btxd: a health-aware mining loop, start and stop scripts and a wallet backup. For larger setups the README points to getblocktemplate with external miners. solo official open source scripts →

    Note Mining needs a qualified GPU and a node that checks blocks itself (matmulvalidation=consensus, the default), not a trusted mirror. See the GPU operator runbook.

Node tools

7 links

  • easynode ↗ (opens another site) Open-source (MIT) desktop app of the easyBTX team that installs and supervises btxd on the machine you already own. desktop open source →

    Note Runs v0.34.15 without the model network. Without a qualified GPU the node follows signers' checks instead of checking the MatMul work itself.

  • BTX Node Guardian ↗ (opens another site) Free script that tells a waiting network from a stuck node and dials helpful peers. It never restarts the node. script watchdog →
  • BTX snapshots ↗ (opens another site) Daily pruned datadir snapshot, checked and signed by a second node. Built on a trusted mirror, so the MatMul work was accepted on signers' attestations. snapshot signed pruned →

    Note Verify the signature and SHA-256 before use. Not for signers.

  • easyBTX UTXO snapshots ↗ (opens another site) UTXO snapshot for loadtxoutset, confirmed by two operators, with SHA-256 of the file and the manifest. snapshot utxo signed →

    Note Check the SHA-256 before use. The JSON names the height; it can lag the chain by a few thousand blocks.

  • Byron Bay UTXO snapshots ↗ (opens another site) UTXO snapshot every 1,000 blocks from the Byron Bay archive node, with SHA256SUMS. The last seven are kept. snapshot utxo →

    Note One signer, the operator. A height is sometimes skipped; then there is no file, not a wrong one.

  • Node help ↗ (opens another site) Known stuck heights with their cause and fix. help stuck heights →
  • AInode ↗ (opens another site) Mac app (Apple Silicon, macOS 13 or later) of the easyBTX team that fetches open AI models over the BTX model network and runs them on your Mac. It only downloads; it never serves, pays or earns. mac model network desktop →

    Note MIT-licensed. This repository holds only the downloads and release notes. Compare the SHA-256 listed with each release.

Wallets

4 links

Caution

We have not audited these wallets. Install a wallet only from the link here. Keep your seed offline, and never type it into a website.

  • BTX Wallet ↗ (opens another site) Official post-quantum wallet in the browser. official browser pq →

    Note Its backup file (.btxwallet) holds the seed in plain text. Keep it offline and never send it to anyone.

  • Node wallet (btx-qt, btx-cli) ↗ (opens another site) The wallet in the official releases: btxd with btx-cli, open source, on your own node. The desktop app btx-qt is in v0.34.15; the v0.34.16 archives leave it out. official desktop open source pq →

    Note Back up the whole wallet with backupwalletbundlearchive (one passphrase-encrypted file; see doc/managing-wallets.md), not only the seed. A .btxwallet export holds the seed in plain text.

  • BTX PQ Wallet ↗ (opens another site) Post-quantum desktop wallet of the easyBTX team for macOS, Windows and Linux. desktop pq mac windows linux →

    Note No independent audit, and the source code is not public. The Mac build is signed and notarized (Bonuz Technology DMCC). Windows and Linux builds are unsigned, so check the SHA-256. Keep the master key or the encrypted recovery file offline.

  • Bonuz ↗ (opens another site) Seedless mobile wallet for iOS and Android with BTX support. mobile ios android seedless →

    Note Seedless means there is no seed phrase you back up yourself. The page says the key is split by MPC, and access and recovery go through the Bonuz login. Check how recovery works before you rely on it.

Buying BTX

1 link

Caution

There is no exchange for BTX. These are trades from person to person without escrow: you pay first and rely on the seller. We have not checked them. Read Before you buy or receive BTX on the start page first, and start with a small amount.

  • easyBTX seller board ↗ (opens another site) Sellers the easyBTX team says it has bought from itself. You agree amount and price with a seller on Telegram and pay them directly, usually in USDT. p2p telegram no escrow →

    Note easyBTX says it holds no funds, is not a party to any trade and quotes no price. On 16 November 2026 the board listed one seller. Contact a seller only through the link on easyBTX's own page. Anyone who messages you first is not that seller. A price agreed there is not a market price.

Bridges and testnets

4 links

Caution

Experimental, and not audited by us. A bridge can lose funds. Do not send more than you can afford to lose.

  • wBTX specification (official) ↗ (opens another site) The developers' design for wrapped BTX on EVM chains: token rules, bridge models and reference contracts. A design, not a working bridge. official spec wrapped ethereum →

    Note Not launched. Its launch checklist is still open and the reference contracts are unaudited.

  • WBTX (wbtx-eth) ↗ (opens another site) Wrapped BTX on Ethereum: contracts, validator services and a local simulator, by the GitHub organisation evxdev. Testnet only. ethereum wrapped testnet →

    Note Last change 2026-07-09.

  • btx.supply ↗ (opens another site) Public tester site and guide of the wbtx-eth project (evxdev): a WBTX bridge on an Ethereum testnet. Test tokens have no value. testnet bridge wip →

    Note Testnet only; it can be reset. Code unchanged since 2026-07-09.

  • Robinhood Chain testnet ↗ (opens another site) The same WBTX test bridge as btx.supply, on the Robinhood Chain testnet. Test tokens have no value. testnet bridge wip →

    Note Testnet only; it can be reset. Code unchanged since 2026-07-09.

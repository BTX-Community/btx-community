      Start here

      New to BTX: what it is, where to ask, and how to keep your coins safe. 6 stops · Needs: a wallet

      BTX is a post-quantum fork of Bitcoin. It has a fixed maximum supply and its own proof of work, called MatMul. Its code is open source, and anyone can propose a change.

      1. 1 What BTX is →

        A few facts, each with its source.

      2. 2 Official introduction ↗ (opens another site)

        Written for v0.33.2. Newer releases differ in places.

      3. 3 How the network is doing ↗ (opens another site)

        The status page, in plain terms.

      4. 4 Ask the community →

        The community group on Telegram.

      5. 5 Choose a wallet →

        Read Before you buy or receive BTX on this page first.

      6. 6 Keep your seed phrase to yourself
        Scam warning

        Never share your seed phrase, your wallet backup file or your private key. Nobody from the community will ever ask for them. Direct messages offering help or “support” are scams.

    • M

      Mine BTX

      Mine with a GPU, alone or in a pool. 4 stops · Needs: a GPU

      Mining needs a GPU. You can mine alone against your own node and keep every block you find. Or join a pool for steadier payouts.

      1. 1 Pick a miner →

        For example easyBTX, an app for Mac and Linux (on Windows through WSL, Microsoft's Linux layer), or matador, which is open source.

      2. 2 Prefer a smaller pool ↗ (opens another site)

        When one pool finds most blocks, the network depends on it. The status page shows each pool's current share.

      3. 3 Use your own btx1z address →

        matador's quick start contains a sample payout address that is not yours, and two pools that are offline. Put in your own address and a pool from our link list.

      4. 4 Problems with an NVIDIA card ↗ (opens another site)

        The official CUDA troubleshooting guide. Parts of it describe the CUDA path from before block 185,000.

    • N

      Run a node

      Keep the network reachable, at home or on a server. 7 stops · Needs: an always-on computer

      Every node relays blocks and keeps the network reachable. A node checks every block itself only with a GPU that passes btxd's self-test. Without one, run it as a trusted mirror that follows signed checks from at least two signers. Otherwise it stops syncing. Signers have the highest requirements.

      1. 1 Easiest start at home: easynode ↗ (opens another site)

        Installs btxd and keeps it running for you.

      2. 2 On a server ↗ (opens another site)

        Linux only (x86_64), with glibc 2.38 or newer, such as Ubuntu 24.04 or Debian 13. v0.34.16 has two archives: a plain one, and -cuda13 for GPU nodes with RTX 50 or RTX PRO Blackwell cards (sm_120). The NVIDIA driver is not included. There is no official Windows or macOS archive.

      3. 3 Before you install: the checklist →

        Where to download, how to check the file, and the settings for a node that holds coins.

      4. 4 Start from a signed snapshot ↗ (opens another site)

        Catches up in minutes from a snapshot. A sync from genesis currently stops at block 126,978 (issue #272).

      5. 5 Node stuck at a height? ↗ (opens another site)

        The node help explains each known case and its fix.

      6. 6 Have a spare machine? →

        Seven ways to give BTX infrastructure, from a home node to a fuzz box (a machine that runs automatic tests).

      7. 7 Run a signer ↗ (opens another site)

        Signers (GPU attestors) need a GPU that passes btxd's self-test, and must stay online. The official CUDA archive covers Blackwell cards (sm_120). Other NVIDIA cards need a build from source and may not qualify. Follow the developers' operator runbook.

    Since March 2026

    BTX roadmap

    Where BTX has been and what comes next, from the git history and the block explorer. Past dates come from release pages and block timestamps.

    Scroll to move along the line

    1. 19 Mar 2026 · Block 0

      ●Done Chain

      Done: Genesis block

      The current BTX chain starts here. From the first block, coins are locked with post-quantum signatures and mined with MatMul.

      More detail on Genesis block

      The current BTX chain starts from a genesis block dated 19 March 2026. The developers call it a 'genesis reset': the chain was restarted from a new first block to launch SMILE v2 private payments. From the start, coins are locked with post-quantum signatures (addresses beginning btx1z), mining uses MatMul, a proof of work based on matrix multiplication, and a private (shielded) pool was open.

      Block 0 on btxscan.io ↗ (opens another site)

    2. 23 Mar 2026 · Blocks 1–50,000

      ●Done Mining

      Done: Mining begins

      Block 1 was mined on 23 March. The first 50,000 blocks came in about six hours and paid the 1,000,000 BTX deployment reward. Since then a block comes about every 90 seconds.

      More detail on Mining begins

      Block 1 was mined on 23 March 2026. A fast-start rule in the code let blocks 1 to 50,000 arrive in about 6 hours 23 minutes (13:06 to 19:29 UTC). They paid 1,000,000 BTX, about 4.8% of the 21 million maximum, all to a single address. After that the chain aims for one block every 90 seconds.

      Block 50,000 on btxscan.io ↗ (opens another site)

    3. Jun 2026 · Block 125,000

      ●Done Network

      Done: Post-quantum links between nodes

      v0.31.0 made nodes talk over a post-quantum encrypted connection whenever both support it. From block 125,000 the private (shielded) pool stopped taking new deposits.

      More detail on Post-quantum links between nodes

      v0.31.0 (5 June) made connections between nodes use a post-quantum encrypted handshake by default whenever both nodes support it, and operators can choose to require it. From block 125,000, reached on 8 June, the private (shielded) pool stopped taking new deposits and only allowed withdrawals, within a rate limit.

      Release v0.32.1 on GitHub ↗ (opens another site)

    4. 10 Aug 2026 · Block 185,000

      ●Done MatMul

      Done: MatMul v4.7: GPU-checked blocks

      Checking a block now means repeating its maths exactly on a supported NVIDIA or Apple GPU. Nodes without one follow signed checks from GPU nodes.

      More detail on MatMul v4.7: GPU-checked blocks

      From block 185,000 (10 August), scheduled by v0.33.2, mining moved to MatMul v4.7. Checking a block now means repeating its work exactly on a supported NVIDIA or Apple graphics chip, so miners and fully checking nodes need one; nodes without one can follow signed checks from GPU nodes, at first using keys named in the release and later keys each operator chooses. The switch was bumpy: an extra rule from block 191,714 (17 August, v0.33.3) stopped difficulty from falling too low.

      Release v0.33.2 on GitHub ↗ (opens another site)

    5. 27 Aug 2026 · closed from block 199,300

      ●Done Supply

      Done: BTX 0.34: private pool closed

      0.34 closed the private pool for good from block 199,300; the roughly 9,689 BTX left inside is treated as burned. The rollout stalled the chain until v0.34.4 and v0.34.5 brought nodes back.

      More detail on BTX 0.34: private pool closed

      BTX 0.34, released 27 August, closed the private pool for good from block 199,300 (mined 24 August, the chain tip when the code was frozen), and the roughly 9,689 BTX left inside it is treated as burned. The rollout was rough: the chain stalled, a rushed fix (v0.34.1) cut about 21 of 94 reachable nodes off the network and the next two fixes left nodes stuck. v0.34.4 on 28 August and v0.34.5 on 30 August brought nodes back, though nodes that had loaded the withdrawn snapshots had to rebuild their copy of the chain.

      Release v0.34 on GitHub ↗ (opens another site)

    6. Sep 2026

      ●Done Models

      Done: Native Model Network arrives

      Nodes gained a helper for finding, checking and sharing open AI models. v0.34.9 on 23 September was the first full release with it. It does not change the coin's rules or spend coins by itself.

      More detail on Native Model Network arrives

      In September BTX added the Native Model Network, a separate helper alongside the node for finding, checking and sharing open AI models, and for funding a model's release or a bounty in BTX. It was built as version 0.34.7, which never had a download of its own; v0.34.9 on 23 September was the first full release to include it, and it added loading and running a model on your own computer. It does not change the coin's rules and does not spend coins by itself.

      Release v0.34.9 on GitHub ↗ (opens another site)

    7. Oct 2026 · Block 244,000

      ●Done Swaps

      Done: Groundwork for swaps

      v0.34.13 and v0.34.14 tightened the hash-lock contracts that cross-chain swaps rely on, enforced from block 244,000.

      More detail on Groundwork for swaps

      v0.34.13 and v0.34.14 tightened the hash-lock contracts that cross-chain swaps rely on, with the new rule enforced from block 244,000 on 10 October. v0.34.13 also added Pay With Compute, which lets an operator charge for access in computing work instead of coins.

      Release v0.34.14 on GitHub ↗ (opens another site)

    8. Nov 2026

      Now Nodes

      Now: Today: v0.34.16

      The latest full release, for Linux. The model network is on by default; SwapNet is included for testing but stays off. New nodes start from a snapshot.

      More detail on Today: v0.34.16

      v0.34.16, first published 7 November and re-issued on 15 November, is the latest full release, for Linux only. The model network is on by default (turn it off with -modelnet=0), while SwapNet, for direct swaps between BTX and BTC or ETH, is included for wider testing but stays off unless you switch it on. A new node must start from a snapshot, because syncing from the first block stops at block 126,978.

    Four reasons

    Why should I be interested in BTX?

    BTX grew out of Bitcoin's code, with three big differences. Payments are locked with signatures designed to withstand quantum computers. Miners use GPUs for the same kind of maths that AI runs on. And its nodes can share public AI models with each other.

    01 · Signatures

    SStart here

    Post-quantum settlement layer

    Signatures designed to withstand quantum computers

    What it means

    Payments are locked with signatures designed to withstand future quantum computers. They follow standards published by NIST, the US standards agency. Since the first block, regular payments can only go to these post-quantum addresses, which start with btx1z. Total supply is capped at 21 million BTX.

    Good to know

    Cross-chain swaps (SwapNet) ship in v0.34.16 for testing and stay off unless you turn them on. The Bitcoin side of a swap uses Bitcoin's own signatures, which are not post-quantum.

    • Source BTX README: post-quantum cryptography (v0.34.16) ↗ (opens another site)
    • More about Post-quantum settlement layer →

    02 · Code

    BBuild

    Built on Bitcoin's code

    Familiar tools, its own chain, open source

    What it means

    The node grew out of Bitcoin Knots v29.2, a version of Bitcoin's software, so its tools and commands work much as Bitcoin users know them. It is a separate chain with its own coins: Bitcoin balances did not carry over. The code is open source under the MIT licence, so anyone can read it, run it or propose a change. It even ships a manual for AI coding assistants (AGENTS.md).

    Good to know

    New nodes still find their first peers through servers run by the original BTX operators, and nodes install signed updates from btx.dev unless you turn that off.

    • Source BTX README: what operators still run (v0.34.16) ↗ (opens another site)
    • More about Built on Bitcoin's code →

    03 · AI models

    NRun a node

    Decentralised model network

    Fetch public AI models from peers, run them yourself

    What it means

    A BTX node is built to find public AI models, fetch them from other nodes, check every piece and pass them on. You run a model on your own computer with your own AI program: the node does not include one, and BTX does not sell AI answers. Default downloads are free and do not spend your coins. It is on by default in v0.34.16; the setting -modelnet=0 turns it off.

    Good to know

    Early stage: v0.34.16 ships it for broader testing. Fetching a model between two separate machines has not been tested yet.

    • Source Native Model Network README (v0.34.16) ↗ (opens another site)
    • More about Decentralised model network →

    04 · Mining

    MMine BTX

    GPU-based proof of work

    Mined with the maths AI chips run

    What it means

    Instead of Bitcoin's brute-force hashing, miners multiply large grids of numbers (matrices), the same kind of maths that takes up most AI work on GPUs. Since block 185,000, a node that checks blocks itself redoes each block's maths on a GPU, and the result must match exactly. There is no CPU mining on the main network.

    Good to know

    Not every GPU qualifies: it must pass the node's own exact-match self-test. v0.34.16 carries reference results for NVIDIA RTX 50-series and RTX PRO Blackwell cards and Apple M4-class chips.
